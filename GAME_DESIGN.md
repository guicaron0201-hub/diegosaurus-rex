# Game Design — Le Parc de Diego

## Scénario

Le parc vient d'ouvrir pour les 1 an de Diego, mais le système de sécurité a été piraté.
Chaque équipe doit sécuriser 3 enclos en résolvant une énigme par enclos, récupérer un code
par enclos, puis combiner les 3 codes au "labo génétique" pour réactiver le système.
Le déblocage final est le signal pour rejoindre tout le monde pour le gâteau.

## Équipes

- ~30 invités répartis en 5-6 équipes de 5-6 personnes
- Mélanger familles/amis et enfants/adultes pour que chaque équipe soit jouable par tous les âges
- Un code d'équipe unique est donné à chaque équipe au départ (sur une fiche de mission imprimée)

## Les 3 enclos

### 1. Enclos des Vélociraptors — le jardin
- **Type d'épreuve** : observation
- **Principe** : des empreintes de griffes (ou objets dino) sont cachées dans le jardin ;
  l'équipe doit toutes les trouver et compter un indice caché sur chacune
- **Code obtenu** : à définir selon le nombre d'objets cachés (ex. 4 chiffres)

### 2. Enclos du Tricératops — la pétanque
- **Type d'épreuve** : adresse physique
- **Principe** : l'équipe doit atteindre un score précis au jeu de boules (ou une variante
  simplifiée pour les enfants) ; le score exact correspond au code
- **Code obtenu** : le score à atteindre, défini à l'avance

### 3. Zone du T-Rex — la forêt
- **Type d'épreuve** : chasse aux indices + interaction physique
- **Principe** : des indices numérotés sont accrochés aux arbres ; il faut les retrouver dans
  l'ordre pour reconstituer un code. Le T-Rex (voir ci-dessous) rôde dans la zone.
- **Code obtenu** : reconstitué à partir des indices numérotés trouvés dans l'ordre

## Rôle du T-Rex (papa en costume)

- Le papa porte un déguisement de dinosaure et joue un rôle actif dans la zone forêt
- **Option "poursuite"** : le T-Rex surprend les équipes ; pour "s'échapper" elles doivent
  relever un défi immédiat (mime, question sur les dinosaures, gage)
- **Option "silence"** (plus douce, adaptée aux jeunes enfants) : le T-Rex "dort" et les
  équipes doivent traverser la zone en silence, sous peine de le réveiller
- **Moment fort de fin** : une fois toutes les équipes réunies pour l'énigme finale du labo
  génétique, le T-Rex peut surgir en costume — ce moment déclenche le passage au gâteau
- Prévoir une consigne rassurante pour les plus jeunes enfants avant le début du jeu

## Labo génétique (énigme finale)

- Combine les 3 codes récupérés dans les enclos
- Une fois validé : écran "Système réactivé" + signal pour rejoindre la maison

## Matériel à prévoir

- Fiches de mission imprimées par équipe (nom d'équipe + code d'équipe)
- QR codes imprimés (un par enclos, si la version QR est développée) ou pancartes avec le nom
  de l'enclos
- Objets/empreintes à cacher dans le jardin (enclos Vélociraptors)
- Indices numérotés à accrocher dans les arbres (zone T-Rex)
- Déguisement de dinosaure (papa)
- Éventuellement : certificats "ranger du parc" à imprimer pour chaque équipe à la fin

## Points encore à trancher

- Textes exacts des énigmes (indices, formulation finale)
- Codes définitifs pour chaque enclos
- Nombre exact d'objets/indices à cacher par zone
- Design des fiches de mission et QR codes à imprimer
